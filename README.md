# DS-Lab

Data Structures Laboratory programs in C.

## Programs Included

| File | Description |
|------|-------------|
| `Ex1A_Array_List_ADT.c` | Array Implementation of List ADT |
| `Ex1B_Singly_Linked_List.c` | Singly Linked List |
| `Ex2_Circular_Linked_List.c` | Circular Linked List |
| `Ex3A_Array_Stack.c` | Array Implementation of Stack |
| `Ex3B_Array_Queue.c` | Array Implementation of Queue |
| `Ex4A_Linked_Stack.c` | Linked List Implementation of Stack |
| `Ex4B_Linked_Queue.c` | Linked List Implementation of Queue |
| `Ex5_Binary_Search_Tree.c` | Binary Search Tree |
| `Ex6_AVL_Tree.c` | AVL Tree |
| `Ex8_Dijkstra.c` | Dijkstra's Algorithm (Graph) |
| `Ex9_Priority_Queue.c` | Priority Queue (Min Heap) |
| `Ex10A_Linear_Search.c` | Linear Search |
| `Ex10B_Binary_Search.c` | Binary Search |
| `Ex10C_Insertion_Sort.c` | Insertion Sort |
| `Ex11A_Hashing_Separate_Chaining.c` | Hashing with Separate Chaining |
| `Ex11B_Hashing_Open_Addressing.c` | Hashing with Open Addressing |
| `Ex12_Student_Record_System.c` | Student Record System |

## How to Compile & Run

```bash
gcc Ex1A_Array_List_ADT.c -o list
./list
```

Replace the filename as needed for other programs.
